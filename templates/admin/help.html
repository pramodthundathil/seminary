Menu Management & Menu Engineer

Create Menu Add Items Edit Delete Reorder
The Menu Management System enables administrators to configure and structure all public navigation menus across the website (Main Navigation Bar, Header Top Menu, Footer Quick Links, and Sidebar Menus). You can create nested drop-down menus, attach custom icons, position menus, link menu items to dynamic pages or external URLs, and drag-and-drop or re-order menu sequence live.
Full Menu Construction & Linking Workflow
1. Create/Publish Web Page (/page/about-us/) ↓ 2. Go to Admin → Menu Management (/menu/admin/menus/) ↓ 3. Click "Menu Engineer" on target Menu (e.g., Main Header Menu) ↓ 4. Click "Add Menu Item" → Fill Item Form (Title, URL/Page, Icon, Order, Parent) ↓ 5. Click "Save Item" → Backend Updates `menu_items` DB Table ↓ 6. Instant Website Update: Menu Item appears in Website Header/Footer/Sidebar
Figure 1: Menu Management Overview list showing menu titles, positions (header/footer/sidebar), active status, and Menu Engineer links.

Step-by-Step Guide: How to Add a New Menu Item and Link it to a Page

1
Step 1: Open Menu Management
In the Admin Sidebar, click Menu Management (URL: /menu/admin/menus/). You will see a list of menus configured for Header, Footer, and Sidebar.
2
Step 2: Click "Menu Engineer"
Click the blue Menu Engineer button next to the menu you wish to modify (e.g. Header Main Navigation).
3
Step 3: Click "Add Item" & Enter Details
In the Menu Engineer form:
• Enter Title (e.g. Academic Courses)
• Under Link Type, select Existing Page and choose your page from the dropdown menu, OR select Custom URL and enter the web address.
• Select Parent Item if you want this to be a drop-down child menu under a parent item (e.g. under Academics). Leave blank for a top-level menu item.
• Enter Menu Order number (e.g., 1 for first position, 2 for second).
4
Step 4: Click Save
Click Save Menu Item. Go to the public website front-end and refresh—your new menu item will be live!

Pages & Website Content Management

Create Page View Edit Delete Publish
The Pages Module allows admins to build and manage static or dynamic website pages (e.g., About Us, History, Statement of Faith, Library Information). Content is authored visually using an integrated CKEditor 5 rich text editor supporting headings, images, tables, video embeds, and formatted copy.
Figure 3: Pages Management list table showing page IDs, thumbnail previews, title/code info, descriptions, active status tags, and action buttons.
Create / Edit Page Form Fields & Specifications
Field Name Field Type Requirement Description & Purpose
Page Title Text Input Required * The main headline of the page displayed at the top of the webpage and in browser title bar.
Code / Slug Text Input Required * Unique URL identifier (e.g., about-us). Resulting public URL will be http://127.0.0.1:8000/page/about-us/.
Page Content CKEditor 5 Rich Text Required * Main body content. Authors can insert formatted text, HTML tables, media images, banners, hyperlinks, and bullet points.
Feature Banner Image Media Selector / Upload Optional Header background image displayed at the top hero section of the public page.
Meta Keywords Text Input Optional Comma-separated SEO keywords for search engine indexing.
Meta Description Textarea Optional Brief summary used by Google and social media preview cards.
Status (Active) Toggle Switch Required * Active: Page is published and accessible to public visitors.
Inactive: Draft mode; returns 404/Private to visitors.
Figure 4: Create Page form interface with Page Title, Slug code, CKEditor text area, banner image selector, and Publish controls.
Page Operations & Consequences
View Page Operation
Clicking View opens a preview modal or opens the live public page at /page/<slug>/ as visitors see it.
Edit / Update Page Operation
Clicking Edit loads the existing title, slug, content, and image into the page editor. Click Update Page to save changes. The updated_at timestamp and updated_by user reference are logged automatically.
Delete Page Operation
Clicking Delete triggers a browser confirmation dialog. If confirmed, the page record is deleted from the database. Any menu items linked to this page will automatically display an unlinked state until updated.

Question Setup & Management

Configure Questions
Exams can contain two types of questions: Objective (Multiple Choice Questions - MCQs) and Descriptive (Essay Questions).
Question Type Required Form Fields Evaluation & Grading Mechanism
Objective (MCQ) Question text, Option A, Option B, Option C, Option D, Correct Option select, Marks. Automated Auto-Grading: System instantly evaluates student response upon exam submission.
Descriptive (Essay) Question prompt text, maximum character limit, Marks allocation. Manual Admin Grading: Student essay appears in Submitted Exams for admin score entry.

Student Requests & Applications

Approve / Reject
When prospective students submit registration forms or program admission requests on the website, they arrive in the Applications Module for administrator review and approval.
Figure 11: Student admission applications table.
What happens on Approval/Rejection?
• Approve: The student status is set to Active, a formal student account is generated, and a confirmation email is dispatched.
• Reject: The request is marked Disapproved with optional feedback comments recorded in the application log.
